# StudySprint

StudySprint is a web-based study task tracker built with HTML, CSS, and JavaScript. It uses a hero-training theme to make organizing study tasks more engaging and motivating.

## Overview

StudySprint allows users to create and manage study missions, track their completion progress, and receive a Hero Rank based on their overall progress.

The project was developed as a hands-on learning project to practice front-end web development and Git/GitHub.

## Features

- Add and delete study missions
- Mark missions as completed or active
- Filter missions by All, Active, and Completed
- Track total, completed, and remaining missions
- Dynamic progress bar
- Hero Rank system based on completion percentage
- Persistent task data using browser localStorage
- Responsive layout for smaller screens
- Hero-themed user interface

## Hero Rank System

| Completion | Rank       |
|------------|------------|
| 0–24%      | Rookie     |
| 25–49%     | Sidekick   |
| 50–74%     | Pro Hero   |
| 75–99%     | Elite Hero |
| 100%       | Top Hero   |
